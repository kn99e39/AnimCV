**상위 제품 목적:** 영상에서 동작을 복원하는 것을 넘어 편집·스타일 변형·사용자 주도 애니메이션 제작을 지원하는 Animation Creation Framework. [PRODUCT_VISION.md](../PRODUCT_VISION.md) §4.1의 확인된 방향을 따른다.

**목표 Architecture:** 원본 Video/Reference → Geometry Observation + FramePose → Pose Hypothesis와 Learned Uncertainty → Reliability-Aware Animation Base → 미래 Conditional Motion Generator → Semantic Constraints + Rig Evaluator → 편집 가능한 Blender Action/FBX.

## 이전 Temporal Lifter 중심 상태 기록 (역사적, 현행 구현 목록 아님)

## 현재 동작 흐름

```text
영상 → 프레임 추출 → 2D 인물 추적 → 시간적 3D 포즈 리프팅
     → 관절 길이 재구성(R2) → 굽힘 평면 안정화(R3)
     → (향후) 제약 기반 IK → FK 키 베이크 → Blender/FBX
```

현재 구현은 2D 관절 좌표를 VideoPose3D 기반의 카메라 상대 3D 타깃으로
변환하고, 인체 길이와 무릎/팔꿈치의 좌우 반전 문제를 보정한다. 이 3D
타깃은 아직 최종 리그 애니메이션이 아니다.

## 좌표계

| 공간 | 축/단위 | 용도 |
| --- | --- | --- |
| 이미지 `I` | 오른쪽 X, 아래 Y / pixel | 2D 포즈 검출 |
| 카메라 `C` | 오른쪽 X, 전방 Y, 위 Z / metre | 리프팅 포즈 |
| 캐릭터 `R` | 오른쪽 X, 전방 Y, 위 Z / metre | 루트 정규화 타깃 |
| 리그 로컬 `L` | Blender bone local / radian·metre | 최종 FK 키 |

자세한 계약은 루트의 `COORDINATE_CONVENTIONS.md`에 있다. 특히 기존
`MotionPoint.position_3d`는 혼합 단위의 깊이 샘플이므로 새 3D 리타깃
입력으로 사용할 수 없다.

## 완료된 범위

1. 좌표계 계약과 Blender의 quaternion/부모-자식 변환 보정
2. 81프레임 시간적 3D 포즈 리프팅 및 낮은 신뢰도 관측의 명시적 추적
3. 피사체별 고정 골격 길이 재구성
4. 무릎·팔꿈치 굽힘 방향 안정화
5. 루트 yaw 추정과 수치 감사
6. 카메라 보정 입력 및 재투영 감사 경로

## 아직 완료되지 않은 범위

- 리그별 hinge axis, pole vector, 관절 한계를 사용하는 제약 기반 IK
- IK 결과의 최종 FK bake와 새 3D 타깃을 통한 FBX 재검증
- 발 접지와 root translation 추정
- 이동 카메라 camera tracking/bundle adjustment
- 다인물·강한 가림·빠른 동작에 대한 확장 검증

따라서 현 단계의 FBX는 기존 2D 리타깃 경로의 산출물이며, 새 3D 보정
결과가 반영된 게임 제작용 최종 FBX는 아직 아니다.
