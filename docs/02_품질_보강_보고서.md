# 3D 포즈 품질 보강 보고서

대상은 `examples/production_demo`의 120프레임·50fps 단일 인물 회전/보행
클립이다. 아래 결과는 최종 3D 타깃 품질에 대한 것이며, 최종 리그
애니메이션 품질 판정은 아니다.

## 초기 실패 기준선

| 항목 | 초기 관측 | 허용치 | 판정 |
| --- | ---: | ---: | --- |
| 좌측 팔뚝 길이 CV | 16.1% | ≤ 10% | 실패 |
| 우측 무릎 굽힘 방향 전환 | 2회 | 0회 | 실패 |
| 최대 root yaw 변화 | 9.03°/frame | ≤ 15° | 통과 |
| 낮은 yaw 신뢰도 프레임 비율 | 3.3% | ≤ 10% | 통과 |

초기 JSON은 실패 사례 보존용으로 유지한다.
`three_d_quality_report.json`은 원시 리프팅, `kinematic_quality_report.json`은
R2 직후의 중간 상태를 가리킨다.

## R1 — 관측 유효성 및 결측 처리

- 낮은 confidence/비가시 2D 관절을 정상 3D 타깃처럼 숨기지 않는다.
- 짧은 구간은 선형 보간, 그 외 구간은 모델 문맥용 nearest hold를 쓴다.
- 출력에는 `observation_valid=false`, `interpolated_input=true`를 남긴다.

| 지표 | 결과 |
| --- | ---: |
| 낮은 신뢰도 입력 | 좌측 손목 9프레임 |
| 명시적 모델 문맥 보간 | 9개 관절 샘플 |
| 조용히 수용된 invalid 3D 타깃 | 0개 |

**판정: 통과.**

## R2 — 골격 일관성 재구성

고신뢰 프레임의 관절 길이 중앙값을 피사체의 고정 길이로 사용해
엉덩이–무릎–발목과 어깨–팔꿈치–손목 체인을 재구성했다. 원본 리프트와
재구성 결과는 별도 파일로 보존한다.

| 지표 | 결과 |
| --- | ---: |
| 8개 감사 limb 길이 CV | 약 0% |
| 평균 3D 보정량 | 6.9 mm |
| 95% 3D 보정량 | 29.5 mm |
| 최대 3D 보정량 | 85.9 mm |
| weak-perspective 중앙 2D 오차 | 8.789 px → 9.091 px |
| 중앙 오차 변화 | +3.43% (허용 +5%) |
| 신뢰 관절 샘플 | 2,031 |

**판정: 단안 입력에서 이용 가능한 증거 기준 통과.** 이 재투영은 실제
카메라 보정이 없는 상태의 2D 보존 프록시이지, 물리적 카메라 오차가
아니다. 자세한 차이는 [카메라 보정 보고서](03_카메라_보정_보고서.md)를
참조한다.

## R3 — 굽힘 평면 안정화

캐릭터 공간에서 상·하위 limb의 외적 부호를 연속적으로 유지한다. 굽힘이
12° 미만인 거의 펴진 관절은 방향이 모호하므로 pole-vector 갱신 및 flip
판정에서 제외한다.

| 지표 | 결과 |
| --- | ---: |
| 좌측 무릎 flip | 0 |
| 우측 무릎 flip | 0 |
| 좌측 팔꿈치 flip | 0 |
| 우측 팔꿈치 flip | 0 |
| 최대 root yaw 변화 | 6.99°/frame |
| 낮은 yaw 신뢰도 비율 | 3.33% |

기존의 우측 무릎 2회는 실제 R3 실패가 아니라, 감사기가 10°를 쓰고
안정화기는 12°를 써서 11.7°의 모호 프레임을 다르게 분류한 문제였다.
두 기준을 12°로 통일한 뒤 최종 보고서는 통과했다.

**판정: 통과.** 근거는
`examples/production_demo/bend_stabilized_quality_report.json`이다.

## R4 — root yaw 신뢰도 융합

어깨와 골반의 양측 축을 각각의 span·관측 confidence·관측 유효성으로
가중해 융합한다. 큰 각도 변화는 hold하고, 각 프레임에 source weight,
어깨–골반 불일치 각도, hold 여부를 남긴다. 실행 순서는 반드시
`R2 재구성 → R4 yaw → R3 굽힘 안정화 → 최종 R4 yaw`다. 마지막 yaw pass는
새 pose와 `character_points`를 일치시키는 단계다.

| 지표 | R3 이전 | R4 결과 | 허용치 |
| --- | ---: | ---: | ---: |
| 최대 yaw 변화 | 6.99°/frame | 13.27°/frame | ≤ 15° |
| low-confidence yaw | 3.33% | 5.00% | ≤ 10% |
| held yaw | 미기록 | 5.00% (6/120) | ≤ 10% |
| 무릎·팔꿈치 flip | 0 | 0 | 0 |

**판정: 통과.** 다만 어깨–골반 방향 불일치의 중앙값은 41.9°, P95는
128.8°다. 이는 걷기 중 torso twist일 수 있으나, R5에서 불확실성으로
반영하기 전에는 고정밀 root 방향의 근거로 과대해석하지 않는다. 근거는
`examples/production_demo/r4_quality_report.json`이다.

## R5 — 추적 가능한 uncertainty

각 3D 관절에 source confidence, invalid 입력, 시간적 가속도, R2 보정량,
굽힘 모호성, torso 축 불일치의 여섯 성분을 기록한다. 이는 확률적 depth
variance가 아니라 단안 입력의 **품질 점수**다.

| 지표 | 결과 |
| --- | ---: |
| 점수화 관절 샘플 | 2,040 |
| 근거 성분이 모두 있는 샘플 | 100% |
| unsafe 기준 | 점수 ≥ 0.55 |
| unsafe 관절 비율 | 0.49% |
| 중앙 / P95 품질 점수 | 0.104 / 0.269 |
| 최대 limb unsafe 비율 | 좌측 forearm 4.17% |
| 미래 retarget 차단선 | limb unsafe > 20% |

**판정: 통과.** `r5_uncertainty_report.json`은 향후 제약 리타깃이
불안정 limb을 거부할 수 있는 sidecar다.

## R6 — 회귀 및 시각 검증

테스트는 관측 invalid, 길이 흔들림, 의도적 무릎 mirror flip, yaw outlier,
카메라 보정 실패, uncertainty traceability를 검출한다. production 데모는
0·60·119프레임의 정면/측면/상단 SVG 검사판을 생성한다.

**판정: 부분 통과.** 기계 검증은 통과했지만,
`examples/production_demo/r6_audit_views.svg`의 자세를 사람이 확인하는
일과 최종 FBX 시각 검증은 아직 남아 있다.

## 제약 리타깃 입력 경계

R3/R5 결과를 직접 소비하는 `constraint_targets.json`을 추가했다. 각
프레임·각 limb에는 character-space root/mid/end-effector, pole vector,
bend angle, 활성화 여부와 차단 사유가 들어간다. 이 데이터는 리그 독립적
이며, 다음 단계의 rig adapter가 실제 bone hinge axis와 rest basis로
변환해야 한다.

| 체인 | 활성 프레임 |
| --- | ---: |
| 좌측 다리 | 120 / 120 (100%) |
| 우측 다리 | 120 / 120 (100%) |
| 좌측 팔 | 110 / 120 (91.67%) |
| 우측 팔 | 120 / 120 (100%) |

좌측 팔의 10개 차단은 low-confidence 손목 관측에서 비롯된
`unsafe_joint_sample`이다. 이는 누락 관측을 억지 IK pose로 바꾸지 않는
의도된 안전 동작이다.
