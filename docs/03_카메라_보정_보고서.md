# 카메라 보정 및 재투영 검증 보고서

## 왜 필요한가

단안 2D 포즈와 pelvis-relative 3D 포즈만으로는 카메라의 초점 거리와
렌즈 왜곡, 인물의 카메라 상대 위치를 확정할 수 없다. 따라서 단순한
2D 형태 보존 검사만으로 실제 거리, root translation, 물리적 재투영
정확도를 주장하면 안 된다.

## 지원 경로

### 1. 명시적 캘리브레이션 — 권장

`animcv_camera_calibration_v1` JSON에 다음을 제공한다.

- 이미지 크기
- intrinsics: `fx`, `fy`, `cx`, `cy`
- OpenCV 호환 radial(`k1,k2,k3`)·tangential(`p1,p2`) 왜곡
- 보정 출처와 checkerboard RMS

입력 예시는 `examples/camera_calibration.example.json`이다.
`audit-calibrated-reprojection`은 이 값으로 pinhole + lens distortion
투영을 계산한다. pelvis-relative 포즈의 프레임별 pelvis translation은
**오직 재투영 오차 계산을 위해** 맞추며, 이를 global root motion으로
내보내지 않는다.

### 2. 고정 카메라 자동 추정 — 제한적 폴백

`estimate-camera-calibration`은 2D/3D 포즈에서 하나의 focal length를
추정한다. 다음을 가정한다.

- 카메라가 영상 전체에서 고정
- principal point는 화면 중앙
- 렌즈 왜곡은 0

추정기는 1px RMS 이내의 가능한 focal 구간을 계산한다. 구간 비율이
1.50배를 넘거나, 해가 탐색 경계에 닿으면 자동으로 거부한다. 이동
카메라에는 이 방식을 사용할 수 없다.

### 3. 미보정 폴백

현재 `audit-reprojection`은 프레임별 weak-perspective affine fit으로
재구성 전후의 2D 보존만 비교한다. 이는 R2의 형태 보존 안전장치이며,
물리 보정 또는 절대 root 이동 검증이 아니다.

## 현재 production demo 결과

| 항목 | 결과 |
| --- | ---: |
| 자동 추정 표본 프레임 | 30 |
| 최적 focal | 2,880 px (탐색 상한 도달) |
| 재투영 RMS | 70.86 px |
| 1px RMS focal 불확실성 | 2.05× |
| 허용 불확실성 | ≤ 1.50× |
| 제한적 calibrated audit 사용 | 거부 |

**판정: 이 데모는 미보정 상태로 유지한다.**
`auto_camera_calibration.json`은 진단용이며, calibrated audit 입력으로
사용하면 안 된다. 근거는
`examples/production_demo/auto_camera_calibration_report.json`이다.

## 해소 순서

1. 실제 촬영 환경에서는 checkerboard로 명시적 보정 JSON을 생성한다.
2. 고정 카메라의 기존 영상은 자동 추정의 불확실성 게이트를 통과한 경우에만
   제한적 calibrated audit을 허용한다.
3. 이동 카메라는 배경 특징점 tracking, ground plane, 사람 포즈를 함께
   최적화하는 camera tracking/bundle adjustment 단계를 별도로 구현한다.
