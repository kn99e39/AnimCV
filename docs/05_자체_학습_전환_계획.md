# 웹 데이터셋 기반 3D Pose 학습 전환 계획

## 목적과 범위

웹 원천 데이터셋으로 2D pose에서 camera-root-relative 3D pose를 학습한다. 직접 촬영,
performer 모집, 촬영 장비 구매는 이 계획의 범위가 아니다. 공개 연구 데이터셋도 학습·평가
후보로 사용한다.

## 데이터 계약

`animcv_supervised_3d_lifter_dataset_v1`은 다음을 한 시퀀스에서 정렬한다.

- canonical 17-joint 2D pose: 정규화한 x/y와 confidence
- camera-root-relative metre 단위 3D GT
- source FPS, image size, sequence ID

2D와 3D는 같은 `frame_index`여야 한다. 원천은 paired RGB/2D/3D annotation을 제공하는
웹 데이터셋이며, source URL·version·checksum·사용 조건을 intake manifest에 기록한다.
원본 데이터는 리포지터리에 넣지 않는다.

## 구현 단계

1. version·checksum·source skeleton/coordinate provenance가 기록된 웹 원천 데이터셋을 source adapter로 canonical paired 2D/3D로 변환한다.
2. invalid-joint supervision mask와 sequence boundary를 보존한 뒤 `build-supervised-3d-dataset`으로 2D pose와 3D GT를 학습 JSON으로 묶는다.
3. `train-supervised-3d-lifter`로 경량 temporal TCN baseline을 학습하고 checkpoint와
   training MPJPE를 기록한다.
4. `evaluate-supervised-3d-lifter`로 학습에 쓰지 않은 sequence를 평가한다.
5. MPJPE/PA-MPJPE/yaw MAE/flip이 기준을 만족할 때만 추론 adapter와 retarget 경로를 비교한다.

## 데이터 분할 원칙

- 프레임 무작위 분할 금지: 같은 source sequence/subject/action clip이 train과 test에 섞이면 안 된다.
- holdout은 원천 데이터셋의 공식 test split 또는 subject/sequence 단위로 분리한다.
- 회전·보행·측면·팔 동작·가림을 holdout에 반드시 포함한다.
- source coordinate frame, camera calibration, GT 누락률을 adapter/intake 단계에서 별도 기록한다.

## 정량 게이트

| 게이트 | 1차 기준 | 의미 |
| --- | ---: | --- |
| tracker success | ≥95% | 입력 대상이 안정적으로 선택됨 |
| PA-MPJPE | ≤80mm | 신체 구조·자세 오차 |
| root yaw MAE | ≤15° | 측면/회전 리그 방향 |
| yaw P95 | ≤30° | 위험 구간의 방향 안정성 |
| knee/elbow flip | 0 (unambiguous) | 리그에 치명적인 반전 차단 |

기준 미달 checkpoint는 실험용으로만 보관하며, 신뢰할 수 있는 FBX 출력의 근거로 쓰지 않는다.

## 운영 체크리스트

- 데이터·모델·생성 artifact의 출처와 사용 조건을 기록한다.
- checkpoint마다 dataset manifest hash, 코드 commit, 학습 config, holdout report를 보존한다.
- 데이터가 추가되면 기존 holdout은 고정하고 새 holdout만 추가한다.
- 각 학습 run 뒤에는 Blender visual acceptance까지 수행한다.
