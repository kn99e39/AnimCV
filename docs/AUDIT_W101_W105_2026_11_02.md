## 3. Findings requiring explicit caution

1. **Scope of harm and CASE A:** W105's statement “zero newly failed rows” in P_leg coexists with **18 newly failed individual rig legs** and **30 reviewed harm rows across PARTIAL**. This is not an arithmetic contradiction: the gate is defined per *row* (any failing leg), so a second leg can become newly wrong while the row was already failing. Do not reinterpret CASE A as “no newly harmful joint/limb.” The report includes seated-cafe source-improvement/rig-regression counterexamples.
2. **Failure ownership is not unique:** W104's R11 coordinates below the existing confidence threshold are often inaccurate relative to the projected reference, and W105 reports residual errors dominated by raw 2D localization. The ordered harm categories are descriptive attribution, not proof of exclusive causal ownership.
3. **GT/camera and sample limitations:** a root-behind-camera reference stratum is retained in the primary historical population and excluded only in an explicitly labelled sensitivity; VAL P_leg contains only 46 rows. Confidence/posture strata are confounded. Meaningful animation evaluation lacks foot contacts, root motion, retargeted game tasks, robust identity coverage and unseen real clips.
4. **Unattended CLI authority (CODE, operational risk):** `scripts/batch_automation.py` starts Claude with `--dangerously-skip-permissions`; its prompt and Git hooks are **not OS-enforced sandboxing**. The pre-commit hook protects staged edits to `docs/next_batch.md`, but cannot guarantee absolute file read-only ownership across all write channels. Keep the worker confined to a trusted Main account and explicitly approved task scope.
5. **Lock scope and final verification (CODE, operational risk):** `active_batch.json` uses local atomic `O_EXCL` and the installation selects a single Main scheduler. This is sound against competing Main-local claimants sharing that state, **not a multi-host global lock**. In `post_verify`, instruction-path edits are searched only in commits bearing the Agent trailer, and the original instruction blob SHA is not separately compared against the final remote blob. There is a detection gap if a write bypasses hook/trailer rules. This audit found no such actual alteration in the 10-commit history.
6. **Progress and evidence provenance:** W101–W105 report Main-local checkpoints, NPZs, videos, Blender files, hashes and executed tests; those binary artifacts are **not in GitHub** and were not accessible for this review. W103 reports 18 focused passes, W104 reports 16, W105 reports 15 plus 50 focused regressions; all are **TEST REPORTED**, not independently rerun. Negative attempts and omissions were preserved in the Worklogs.
7. **Pre-existing W99A production risks remain:** M8 batch parity, actual Depth Anything parity, Blender frame-set behavior, optimized key collapse, checkpoint loading boundaries and public root-yaw export were not certified in W101–W105. New diagnostic PASS cannot override them. The historical `examples/production_demo/README.md` 120-frame audit vs current clip decoding to 199 frames remains a documentation discrepancy, not repaired here.

## 4. Architecture judgment

**Supported:** The actual M1 input can reach frozen S0 on aligned, correctly associated samples (W102). Missing limbs are a major failure mechanism under controlled removal (W104). Reintroducing retained but low-confidence raw joints can improve the fixed rig's leg geometry in the measured P_leg population (W105).

**Not supported:** General reliability for unknown users or camera views; production R11 deployment; a safe full-body/editable animation pipeline; real-time temporal continuity or foot contact; correction of identity failures; attribution of all remaining failures solely to S0, the detector or IK.

**Next-review boundary:** This audit closes the **W101–W105 code-audit obligation only**, with the above documented risks. The subsequent architectural choice must distinguish a permissible bounded evidence-only validation from the user-owned decision to change observation policy or downstream architecture. Do not quietly cross that decision boundary.
