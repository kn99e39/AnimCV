## 3. Architecture risks and evidence boundaries

- Ownership: In the tested mixed W102 rig, S0 drives legs, HMR2 torso/root and J1X arm; real_s0_only instead uses S0 left-arm output. Joint-name correspondence alone does not establish actual channel ownership.
- User intent: W115 reports a D2 edit accepted under local tail-joint authority that moves world-locked joints up to 3.4 mm. Conversely, stored quaternion changes can leave world points bit-identical. These are distinct product semantics, not a threshold tweak. No permanent policy is approved.
- Identity/time: tracked same-person continuity UNKNOWN for 199/199 real frames and 319/319 benchmark rows. The scratch candidate fails closed for identity-dependent cross-frame operations; it does not solve tracking. The 50fps source versus 30fps Action has 198/199 mismatched keys and a 2.64s last-key discrepancy. Sidecar time is not an Action/FBX time contract.
- Confidence: raw detector scores >1 remain valid raw observations; no calibrated 3D confidence is available. No production schema migration was approved or implemented.
- Authenticity: the W115 semantic comparator rejects mutations relative to trusted reference inputs. Re-hashed SHA chains are not proof of external authenticity against an adversary able to rewrite both reference and candidate. The tested populations and schemas are narrow.
- Utility: W112–W115 are four consecutive CASE D verdicts, and W113–W115 three consecutive invalid Animation Base tests. Synthetic edits and storage equality do not establish occlusion completion, expressive control, temporal/contact quality, style reconstruction, usable editable rig animation, or production readiness.
