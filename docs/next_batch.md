## PURPOSE

W131 ran authentic CondMDI and preserved the edit footprint, yet produced a 429 mm left-arm entry discontinuity against 24 mm for slerp and lost source timing. W130 and W133 were **checkpoint-rights blocked**, not model-quality failures. W133 additionally found that the official OmniControl inference path constructs SMPL and loads AMASS-derived HumanML3D data; it did not execute a model. Repeating an MIT-code/ambiguous-weights preflight is not useful.

A materially different official option is now evidenced: NVIDIA's **ARDY-SOMA-RP-30FPS-Horizon60** checkpoint is explicitly released under the NVIDIA Open Model Agreement, with global deployment geography, a 30-joint SOMA representation, **native 30 fps**, sparse joint-position/rotation control, and real motion tensors. Its 2026-10 release is distinct from the older 20/25-fps ARDY variants. Official code is Apache-2.0. Unlike Kimodo's documented end-effector convenience constraint, which also injects root/heading and rotations, ARDY exposes a lower-level motion-conditioning interface; however, whether this interface can express ONLY the S1-supported left-wrist XYZ observations without synthetic root/full-body channels is **unverified**. ARDY also uses the **gated Meta-Llama-3-8B-Instruct** text encoder and a separately licensed LLM2Vec stack. Do not assume the required authorized access exists. This batch must fail closed if it does not.
