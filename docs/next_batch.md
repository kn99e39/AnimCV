## PURPOSE
The strongest remaining product problem is actual generated animation quality. W122 found a source-perception-dominated, far-arm discontinuity on real S1 kettlebell footage: source wrist jump ~0.4 m in one 30-fps frame at SOURCE frame 251, with a visible release/reversal artifact. W123's learned error signal is not calibrated to authorize edits; W128's Unity license block is irrelevant here. We need evidence of a pretrained model's real rig utility, not another diagnostic around the same heuristic.

## CENTRAL INTENT
Can ONE reproducible pretrained MotionBricks SOMA inbetweening model, conditioned on verified context/target poses from a frozen real-video-derived BaseRig Action, generate a more natural, temporally coherent **left-arm-only candidate** through S1's known source discontinuity, while preserving exact original source timing, all out-of-domain tracks and hard user pins? Show the candidate on the SAME Blender rig, alongside no-op and simple interpolation controls, at native 30 fps. The output is a SCRATCH PROPOSAL, never an automatically accepted Action. A negative result (e.g. partial-body conditioning cannot transfer, mismatched temporal semantics, loss of source intent, or no visual benefit) is a valid completed result and informs whether this generator family fits AnimCV.
