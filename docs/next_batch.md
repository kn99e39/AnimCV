## PURPOSE
W129 executed real pretrained MotionBricks and authored an isolated Action but lost the overhead-press intent and underperformed simple slerp. W130 was blocked by checkpoint rights, not by model quality. W131 executed CondMDI with an honest partial-observation mask and safe rig projection but produced a 429 mm arm-local entry step versus 24 mm for slerp. W132's exact ON/OFF comparison established that diffusion-step replacement does not alter the generated masked interior; the learned conditioning path generated a trajectory incompatible with the observed source. On a model-generated reference, position-only masking was much worse than pos+rot+velocity, but that reference is closed-loop synthetic and does NOT prove causation on S1. The S1 source is GT-free and partially occluded; adding fabricated rotations or root travel is prohibited.

An independently developed pretrained model with explicit sparse joint-position guidance is therefore a meaningful alternative architecture hypothesis. OmniControl (ICLR 2024) advertises spatial control at arbitrary joints/times, has official inference code and a public HumanML3D checkpoint, and works with 20-fps, 22-joint HumanML3D motion. Its code is MIT, but the externally hosted checkpoint, HumanML3D/AMASS data, optional SMPL assets and other dependencies have separate rights questions; do not infer weight rights from the code license. Its official sampling path has a 196-frame convention and may require normalization assets and legacy dependencies. Spatial control accuracy, source faithfulness, S1 representation compatibility and actual Blender-rig quality are UNPROVEN. This batch tests them rather than presuming success.
