## PURPOSE
W110 produced promising, narrowly bounded held/smooth recovery observations, but its predeclared fresh-repeat validity gate failed because newly exported mixed FBX files differed in Python-hash-derived UIDs, UID-induced order, timestamp and embedded source path. ## CENTRAL INTENT
Is FBX-embedded interpolation metadata plus a deterministic, source-independent consumer mapping invariant to producer-specific FBX UIDs, object ordering and source-file paths, while still detecting actual changes to curves, key data, connection topology and animation semantics?
